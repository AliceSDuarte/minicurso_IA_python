O que é Ciência de Dados?

É transformar dados em decisão: coletar, organizar, entender o que os números dizem e, a partir daí, estimar o que ainda não sabemos.

Estatística
medir incerteza e tirar conclusões dos dados
Programação
automatizar e escalar a análise (Python)
Domínio
conhecer o negócio — no nosso caso, risco

Não é só “rodar um modelo”. É entender o problema, os dados e o risco por trás deles.

Modelagem · interativo

Determinístico × Estocástico

Determinístico
mesma entrada → mesma saída. Um único número. Ex.: juros compostos, projeção fixa.
Estocástico
inclui o acaso → uma distribuição de resultados. Ex.: projeção de sinistros, rentabilidade.
Projeção de um valor ao longo de 60 meses

Foco nos estocásticos: risco é incerteza. Precisamos de cenários, não de um número só.

Modelagem · quando usar cada um

Por que precisamos dos dois

Não é “um contra o outro”. Cada abordagem responde a uma pergunta diferente.

Determinístico → método auditável
Mesma entrada gera sempre a mesma saída. Qualquer pessoa — inclusive um auditor — refaz o cálculo passo a passo e chega no mesmo número. É a base de memórias de cálculo, valores contratuais e tudo que precisa ser replicável e defensável.
Estocástico → cenários e risco
Gera uma distribuição de resultados. Dela tiramos o cenário pessimista, o base e o otimista — e medimos a chance de cada um. É o que responde “e se der errado?” em provisões, stress test e decisão sob incerteza.

Uma linha para auditar · um leque para enxergar o risco.

Método estocástico · interativo

Simulação de Monte Carlo

Pra que serve
sortear milhares de cenários possíveis e ver a distribuição dos resultados — média, probabilidades e caudas (ex.: VaR, prob. de ruína).
Quando usar
quando o resultado depende de várias incertezas e não existe fórmula fechada.
Valor de uma carteira após 1 ano (início = 100)

O que é IA Preditiva?

“A inteligência artificial (IA) preditiva envolve o uso de análise estatística e aprendizado de máquina (ML) para identificar padrões, antecipar comportamentos e prever eventos futuros. As organizações utilizam a IA preditiva para prever possíveis resultados futuros, causas, exposição a riscos e muito mais.” — IBM
IA Preditiva — o objetivo é prever / estimar.
“Qual a chance deste segurado ter sinistro no próximo ano?”
IA Generativa — o objetivo é criar conteúdo.
texto, imagem, código. É outra família de problemas.

No mundo atuarial: probabilidade de sinistro, churn de segurados, precificação e reservas.

Alguns modelos preditivos

Do mais simples e interpretável ao mais poderoso. Não existe “o melhor” — existe o adequado ao problema.

Machine Learning

Redes Neurais Artificiais (RNA)

Camadas de “neurônios” que ajustam pesos até aprender a relação entre entrada e saída. Inspiradas — de longe — no cérebro.

  • Entrada → camadas ocultas → saída
  • Brilham com muitos dados e padrões complexos (imagem, texto, séries)
  • Para tabelas pequenas, modelos mais simples costumam bastar

Hands-on: prevendo o custo

Mesma base real. Vamos prever o custo (charges) a partir das características da pessoa e medir o quanto acertamos.

modelo_preditivo.ipynb
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import r2_score

df = pd.get_dummies(df, drop_first=True)   # texto → número
X = df.drop(columns="charges")          # variáveis
y = df["charges"]                       # o que prever

Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.2)
modelo = RandomForestRegressor().fit(Xtr, ytr)

pred = modelo.predict(Xte)
r2_score(yte, pred)                    # quão bem acertamos
